Announcing Toise 0.9.2 — a timeline for the example viewer

Released 2026-07-03 · written up 2026-09-30

0.9.2 touches only examples/graph-viz, the standalone, dependency-free page that reads the GraphQL API. The server and the pkg/emit SDK are unchanged, so the binaries behave exactly as 0.9.1 does.

The viewer is an example, not a product surface. What it shows off is a property of the engine: any past instant can be read back exactly.

Scrubbing through history

A graduated timeline with absolute time labels lets you drag a cursor to any past instant and see the topology as it was, through the entities(asOf:) and relations(asOf:) arguments. A replay mode plays that history forward like a video.

Behind the timeline, a change-density heatmap shows one row per entity type, so busy periods stand out at a glance. Heartbeats are excluded, so the heatmap counts real changes. Dragging across it zooms the timeline into that period.

A calmer layout

  • The layout settles into hub clusters before it is shown, then stays put.
  • Edges are faint and unlabelled by default; a toggle switches them on, to labels, or off.
  • A search filter isolates everything matching a query, such as one application.
  • The detail panel is resizable, and long values wrap instead of clipping.

Get it

go install github.com/toise-dev/toise/cmd/toise-server@v0.9.2

Binaries for linux and darwin (amd64 / arm64) are on the release, each with a checksum, and the container image is on GHCR. See the 0.9.2 docs and the changelog.
