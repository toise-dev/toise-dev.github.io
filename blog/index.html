Release announcements

What changed in each release, why, and what to check before upgrading. Newest first.

  • 0.18.0 · 2026-09-30

    Toise 0.18.0 — making the graph legible

    0.17.0 set out to say what an answer is worth. 0.18.0 makes the answer readable to the MCP client or GraphQL caller that reads it.

  • 0.17.1 · 2026-09-22

    Toise 0.17.1 — five fixes from field use

    Five small fixes from the first week of 0.17.0 in the field.

  • 0.17.0 · 2026-09-21

    Toise 0.17.0 — saying what an answer is worth

    A handle that survives failover, identities written inline, and timestamps that state their own resolution.

  • 0.16.0 · 2026-09-01

    Toise 0.16.0 — holding up at fleet scale

    The incident window at 10,000 hosts, in milliseconds. Every answer states its own scope and freshness.

  • 0.15.0 · 2026-08-20

    Toise 0.15.0 — answers that explain themselves

    The data was already there. This release makes the answers say how to read them.

  • 0.14.0 · 2026-08-17

    Toise 0.14.0 — reachability, and the first deprecation

    A fourteenth entity type for the boundary an incident actually asks about — and the first thing we have promised to remove.

  • 0.13.0 · 2026-08-13

    Toise 0.13.0 — one answer per question

    Three questions that had two answers, or none — and what it costs when a contract stays silent and a producer fills the gap in good faith.

  • 0.12.0 · 2026-08-11

    Toise 0.12.0 — the pod

    A thirteenth entity type for the unit of scheduling and of failure — and the argument that settled it was telemetry, not taxonomy.

  • 0.11.0 · 2026-08-11

    Toise 0.11.0 — vocabulary and correlation

    A correlation answer that was quietly wrong, and the type vocabulary producers can finally import instead of retyping.

  • 0.10.0 · 2026-07-30

    Toise 0.10.0 — delete provenance and host-scoped endpoints

    Delete provenance on every disappearance, host-scoped loopback endpoints, and the producer-contract rules that came out of a real flapping incident.

  • 0.9.2 · 2026-07-03

    Toise 0.9.2 — a timeline for the example viewer

    An example-only release: the graph viewer gains a time-travel timeline and a change-density heatmap.

  • 0.9.1 · 2026-07-03

    Toise 0.9.1 — hardening after an engineering review

    A patch release from a full engineering review: correctness fixes, security hardening, and same_as beliefs end to end.

  • 0.9.0 · 2026-07-01

    Toise 0.9.0 — strict spec alignment and read-surface security

    Full AnyValue descriptions, entity delete reasons, mTLS-only ingest decoupled from read tokens — all additive, with the zero-config single binary unchanged.

  • 0.8.0 · 2026-06-22

    Toise 0.8.0 — the SaaS-readiness release

    Access security, resilience and HA, and multi-source identity — all opt-in, with the zero-config single binary unchanged.

  • 0.7.0 · 2026-06-16

    Toise 0.7.0 — the integration release

    Operator annotations, MCP resources and prompts, token roles, and a conformance CLI for producers in any language.
